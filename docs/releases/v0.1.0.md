# DSH Workproof 0.1.0

作者：牛村木木山。首批两个独立安装的社区插件，面向 **DeepSeek Harness 0.2.0-rc.2 / Node.js 22+ / macOS 本地工作区**。

## 交付回执 / Delivery Receipts

登记本轮产出的文件，分开显示 Agent 的检查声明、插件观察的大小与 SHA-256，以及你的版本验收意见。重新检查发现文件变化后，旧接受不会覆盖新内容；需显式建立基线并重新验收。支持有界纯文本预览和本地 Markdown 下载。

- 文件存在、哈希一致，不代表内容正确或测试执行过。
- 用户接受不代表已发送给外部收件人。模型工具不能替用户接受。
- 仅读取明确登记的本地文件，无后台监听或自动上传。

## 研究证据账本 / Evidence Ledger

连接事实断言、推断、建议、来源定位、支持/反证关系和待解决问题。整份账本内容修改后清除旧审阅；导出前显式选择论点，默认省略摘录、审阅备注和本地引用路径，并先展示 Markdown 预览。

- 不抓取或读取被引用的来源，不自动核验真伪。
- 选中范围和隐私省略只控制导出的 Markdown；所属本地会话仍能读取完整账本。
- 没有结构性警告，不等于推理成立。

## 安装

两个 `.tgz` 都是预构建插件包，无需 npm 账号，包自身不含安装时脚本。先下载资产并对照 `SHA256SUMS`；安装时包管理器仍可能下载依赖。安装到应用实际使用的 profile，不要覆盖另一个 profile：

- [交付回执：中文安装与使用](https://github.com/piggy00544/dsh-workproof/blob/main/packages/dsh-delivery-receipts/README.zh.md)
- [研究证据账本：中文安装与使用](https://github.com/piggy00544/dsh-workproof/blob/main/packages/dsh-evidence-ledger/README.zh.md)

Harness rc.2 的空白会话隐藏会话标签，先进入已有普通会话。插件可以独立安装，不互相依赖。

## 验证与边界

[分层验证记录](https://github.com/piggy00544/dsh-workproof/blob/main/docs/verification.md)逐项区分源码、真实宿主、安装包、UI、重装与公开下载验证。示例均为合成内容，没有内部数据、模型密钥或原始对话。

GitHub 托管 CI 尚未运行：当前 OAuth 授权缺少创建工作流的权限；仓库内保留未启用的 CI 模板。本地测试结果不冒充远端 CI。其他系统、远程工作区和 Harness 版本尚未完成端到端验证；插件也不是宿主代码执行权限之外的安全沙箱。
