# A draft can change after it was accepted

Synthetic demonstration only. This is not a published article or a real person's account.

Draft version: one

A file can be readable, nonempty and unchanged without being a good draft. A receipt records the file version that a reviewer saw. Editorial judgment still requires reading the words.

For the stale-version walkthrough, accept this version in the receipt UI, then change the version line from `one` to `two`. Rechecking should mark the old receipt stale. Creating a new receipt version should clear the earlier acceptance.

No publication or external delivery has occurred in this example.
